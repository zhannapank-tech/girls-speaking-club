# Girls' Speaking Club

Landing page for Girls' Speaking Club by @janna.speaks. Single self-contained file: `index.html` (images inlined, fonts from Google Fonts).

English version: open the page with `#en` at the end of the link, or tap EN at the top.

## Publish with GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.
The site appears at `https://<username>.github.io/<repo>/` in a minute or two.
